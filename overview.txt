#########################################################################################################################################################################
#                                                                                Syntax                                                                                 #
#########################################################################################################################################################################

1) Create database:

          create database database_name;

2) Create table:

          create table table_name 

          (column_1_name [int, bigint, smallint, numeric(p, s), float, boolean, char(n), var_char(n), date, ...] {unique} {primary key}... , ...);

3) Select rows:

          select { distinct } ...

          from table_name

          {
            { inner | left | right | full } join [table_name]
            [ on ... | using (...) ]
          }

          { where ... }

          {
            group by ...
            { having ... }
          }

          { order by column_1 { desc | asc }, column_2 { desc | asc }, ... }

          { limit n }

          { offset n }

          ;

4) Update table:

          update table_name

          where condition_1 { [ and | or ] condition_2 ...} ;

5) Insert row:

          insert into table_name { (column_name_1, ...) }

          values (value_1_1, ...) {, (value_2_1, ...), ... } ;

6) Delete row:

          delete from table_name

          where condition_1 { [ and | or ] condition_2 ...} ;

7) Conditional statement:

          case

          when _1_true_ then do_this_1 

          { when _2_true_ then do_this_2 , ...} 

          { else [else_do_this] }

          end



#########################################################################################################################################################################
#                                                                            Execution Order                                                                            #
#########################################################################################################################################################################

1) from / join
2) where
3) group by
4) having
5) select
6) distinct
7) order by
8) limit / offset



#########################################################################################################################################################################
#                                                                 Other PostgreSQL Functions and Syntax                                                                 #
#########################################################################################################################################################################

1) string_agg(value, append_string)  =>  String concatenation aggregate function.

2) extract ([year | month | day] from date_value)  =>  Extract fields from the date.

3) length(string)  =>  Finds number of characters in the string.

4) octet_length(string)  =>  Finds number of bytes in the string.

5) [ row_number() | dense_rank() | rank() |
     sum() | avg() | count() | max() | min() |                      => Window functions. "partition by column_name" means group by "column_name" and calculate for each.
     lag() | lead() | first_value() | last_value() | nth_value()
   ] over ( { partition by column_name } order by column_name)



#########################################################################################################################################################################
#                                                                          Important Concepts                                                                           #
#########################################################################################################################################################################

1) Aggregate functions skips "null" values.

2) Aggregate functions collapses rows.

3) Window functions are like aggregate functions but it doesn't collapse rows.

4) Window functions support grouping and ordering.

5) order by column_1 { desc | asc }, column_2 { desc | asc }, ...   => Starts ordering from left, upon conflict moves to the next column as tie breaker.
